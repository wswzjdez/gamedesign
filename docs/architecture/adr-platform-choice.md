# ADR-001：平台与技术选型

- **状态**：已采纳（2026-10-17）
- **决策人**：技术总监 + 制作人

## 背景 (Context)
目标：面向中学生的纯娱乐模拟经营游戏，作为个人作品集。
约束：单人开发、需在线可演示、未来可能进校或上架移动端。
可选：先 Web、先手机、四端并行。

## 决策 (Decision)
1. 引擎选定 **Unity 6 LTS**（跨端同一代码库、WebGPU/WebGL 运行时、Sentis AI、APV/STP 性能特性）。
2. **MVP 先 Web + PC**，跑通核心循环并产出可在线 Demo；移动端（Android/iOS）在 S4 扩展。
3. 渲染管线 **URP**。

## 理由 (Consequences)
- **正面**：Web 零安装 → 作品集/进校演示门槛最低；同一代码库跨端，后期成本低；Unity 6 性能特性让中低配设备也流畅。
- **负面/风险**：WebGL 性能与内存受限，需控制首包与对象数；移动端需补实名防沉迷与触屏 UI，S4 单独排期。
- **暂缓**：Multiplayer Center 本期不做（合规重、留存难），仅预留接口。

## 备选被否
- 四端并行：单人易拖垮，否。
- 先手机：早期无法在线 Demo 作品集，否。
